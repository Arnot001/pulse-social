PULSE // SOCIAL BETA
Version 0.1.0-beta.1

This beta is designed for Windows 10/11.

FIRST RUN
1. Open Pulse Social from the Start menu or desktop shortcut.
2. Click GET STARTED for the in-app guide.
3. Use Pulse Browser / PDH from the launcher. Pulse uses a dedicated browser profile.
4. Log in to X or TikTok inside that Pulse browser profile when a tool needs it.
5. Use Dry Run / Preview before destructive cleanup actions.

SUPPORTED BROWSERS
Pulse looks for Brave, Chrome, or Microsoft Edge. Brave is preferred for the current beta.

LOCAL DATA
Pulse Social stores runtime data under:
%LOCALAPPDATA%\Pulse Social

That includes the dedicated Pulse browser profile and local app state.
Pulse Social does not need Git, Python, VS Code, or a terminal on the customer PC.

BETA NOTES
- TikTok Shop category collection uses the bundled Pulse Data Hunter extension.
- Emoji artwork is bundled locally and works offline.
- Some third-party websites can change without notice. If a collector stops working, close it and report the error/status shown in Pulse.
- Cleanup actions are confirmation-driven. Review the target list before running destructive actions.
