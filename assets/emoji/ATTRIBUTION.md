# Emoji artwork attribution

Pulse Social includes local PNG emoji artwork from the Twitter image set distributed by
[emoji-data](https://github.com/iamcal/emoji-data).

The emoji-data project is Copyright (c) 2013 Cal Henderson and is distributed under the MIT License.

Twitter/Twemoji graphics are licensed under the Creative Commons Attribution 4.0 International
license (CC BY 4.0). Original Twemoji project:
https://github.com/twitter/twemoji

The artwork is bundled locally so the Pulse Social emoji picker does not require a runtime
network connection.
